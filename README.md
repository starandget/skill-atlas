# 星图 · 技能树编辑器

基于 React + Vite 的本地技能树画布。

## 启动

npm install
npm run dev

## 使用

- 空白处右键新增节点；点击节点后在右侧编辑名称、描述、分类和等级。
- 拖动节点调整位置；按住右键拖动画布平移（右键单击仍打开菜单）；滚轮缩放。
- 节点右键可删除或开始连线；点击另一个节点完成连接。
- 右侧连接列表可移除连线；选中节点后也可按 Delete 删除。
- 数据自动保存在当前浏览器。导出 JSON 可备份，导入可恢复并替换当前星图。
- 工具栏的适应画布按钮可显示全部节点。

npm run build 生成 dist 目录。

## 变量与节点效果

右上角“变量管理”可创建数值或布尔变量、修改基准值、查看所有已生效节点计算后的结果。选中节点后，在“变量效果”中绑定一个或多个变量。

数值效果每级应用一次，0 级不生效：
- 加 / 减固定值：每级加 / 减填写的数值。
- 增加 / 减少百分比：每级加 / 减基准值乘以填写的百分比。
- 乘百分比：每级乘以填写值除以 100；5 表示 ×0.05，105 表示 ×1.05。

布尔效果在等级大于 0 时赋值为 true 或 false。计算按照节点创建顺序及节点内效果顺序进行；多个布尔赋值以最后一个为准。删除变量同时移除其节点效果绑定。变量与效果一并自动保存、导出和导入，旧版无变量的存档仍可导入。

计算与存档校验测试：node --test src/variables.test.js
