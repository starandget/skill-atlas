# 星图 · 技能树编辑器

基于 React + Vite 的本地技能树画布。

## 启动

npm install
npm run dev

## 使用

- 空白处右键新增节点；点击节点后在右侧编辑名称、描述、分类和等级。
- 拖动节点调整位置；按住右键拖动画布平移（右键单击仍打开菜单）；滚轮缩放。
- 节点右键可删除或开始连线；点击另一个节点完成连接。
- 右侧连接列表可移除连线；选中节点后也可按 Delete 删除。
- 数据自动保存在当前浏览器。导出 JSON 可备份，导入可恢复并替换当前星图。
- 工具栏的适应画布按钮可显示全部节点。

npm run build 生成 dist 目录。

## 变量与节点效果

右上角“变量管理”可创建数值或布尔变量、修改基准值、查看所有已生效节点计算后的结果。右键点击节点并选择“编辑”，在编辑弹窗中的“变量效果”绑定最多一个变量。

每个普通技能节点必须关联一个数值变量才能保存。效果固定为每级增加指定的固定数值；等级为 0 时不生效。布尔变量仍可在变量管理中管理，但不能绑定到技能节点。变量的新增、编辑和删除都在“变量管理”中完成；节点编辑弹窗只提供变量选择和每级数值。旧存档的数值效果会转换为固定加法，节点上多余绑定只保留第一项。
计算与存档校验测试：node --test src/variables.test.js
